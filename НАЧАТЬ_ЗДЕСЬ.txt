ПАРСЕР ЗАЯВОК PROFI.RU ПО АВТОМАТИЗАЦИИ — LINUX-СЕРВЕР
======================================================

Первый запуск:

1. Откройте терминал в папке проекта.
2. Выполните: bash install.sh
3. Откройте настройки: nano .env
4. Заполните PROFI_LOGIN. BOT_TOKEN уже можно заменить на рабочий.
5. Для защищённого режима укажите ADMIN_CHAT_ID. Если оставить его пустым,
   бот будет доступен любому пользователю в личном чате.
6. Откройте Telegram-бота и отправьте ему /start.
7. Выполните: bash check.sh
8. Выполните: bash start.sh
9. Когда бот запросит SMS-код Profi.ru, отправьте ему только цифры кода.

Графический браузер и ручной login.bat на Linux-сервере не нужны. Бот сам
создаст data/storage_state.json после получения SMS-кода.

Постоянная работа после проверки:

1. Выполните: bash service.sh install
2. Выполните: sudo loginctl enable-linger "$(whoami)"

Управление:

bash service.sh status   — проверить состояние
bash service.sh logs     — смотреть журнал
bash service.sh restart  — перезапустить
bash service.sh stop     — остановить
bash service.sh start    — запустить

Команды Telegram: /status, /health, /version, /renew, /cancel, /resume, /help.

Если бот прислал CAPTCHA или сообщение об ограничении:

1. Парсер уже полностью остановил обращения к Profi.ru.
2. Посмотрите присланный скриншот.
3. Когда можно повторить проверку, отправьте /resume.
4. Если ограничение осталось, бот снова перейдёт на безопасную паузу.

/health показывает Telegram, Chromium, cookies, heartbeat, последнюю успешную
проверку Profi.ru и свободное место на диске.

ВНИМАНИЕ: в открытом режиме все пользователи получают заявки и могут управлять
восстановлением сессии. Для рабочего аккаунта безопаснее указать ADMIN_CHAT_ID.

Файл .env содержит секретный токен. Не передавайте его посторонним.
Подробная инструкция находится в README.md.
